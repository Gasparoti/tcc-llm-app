# tcc-llm-app
Protótipo em Next.js para criação e estruturação de prompts educacionais com IA. Permite gerar, refinar e revisar respostas, classificando afirmações e calculando métricas heurísticas. Desenvolvido para incentivar a engenharia de prompts, o pensamento crítico e a avaliação humana de conteúdos gerados por LLMs.
